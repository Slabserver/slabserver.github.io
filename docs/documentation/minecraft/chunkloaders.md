# Chunkloader Guidelines

!!! note
    You must have permission from the staff team before using any chunkloaders - see [Requesting Permission](#requesting-permission) below.
    !!! warning
        Staff reserve the right to disable a chunkloader at any time if it affects server performance for other players.

## Guidelines

- Chunkloader use must be kept to a minimum. Chunkloader arrays are not permitted.
    - Permanently active chunkloaders are limited to `(simulation distance + 1) ÷ 4`, rounded down.
        - Typically, this means players may have up to 2 permanently active chunkloaders.
    - Temporary chunkloaders for specific purposes, e.g. while a minigame is being played, may exceed this limit at staff discretion.
- Chunkloaders must be easily disabled, with clear instructions provided on how to disable them.
- Chunkloaders should automatically turn off when no longer needed.
    - e.g. a farm must disable both the farm and the chunkloader when storage is full.
- All loaded chunks must comply with existing server rules, such as our [Anti-Lag Guidelines](lag.md).
    
## Requesting Permission

To request permission for a chunkloader, message **@Chester** with the following information:

- The **intended purpose** of the chunkloader.
- The **exact coordinates** where the chunkloader can be disabled, with instructions on how to do so.
- Any **additional features**, such as an auto-shutdown after a set time (e.g., "turns off after 5 minutes").
- **Confirmation** that you have read and understood the [Guidelines](#guidelines) above.
- (Optional) Any other relevant details, such as MSPT estimates.

If approved, the staff team will add the chunkloader to an internal spreadsheet, for our own documentation and reference.
