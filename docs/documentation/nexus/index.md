# The Nexus

The **Nexus** is Slab's archive and minigame server. Every server on it runs ViaVersion, so any 1.21.4+ client can join.

![cover](../../assets/images/nexus/cover.png)

The Nexus isn't trying to replace the big public minigame servers. It's a home for content that belongs to Slab and is built around this community's history.

Over the years, players have built and played plenty of games in survival. They were fun, but survival has limits: items run out, things get broken, and only one copy exists. The Nexus fixes that. Games get instancing, build protection and automatic resets, so they work as proper multiplayer experiences without losing what made them fun the first time.

## Philosophy

Two goals drive everything here.

**Preserve, but improve.** The game stays the same while the experience around it gets better. For example, Hurtin' Slabbers deliberately keeps its poison, even though health could have been set with commands.

**Exclusive to Slab.** Some content exists only here. These aren't ports of other servers. They're built around this community and aren't available anywhere else.

## How It Works

Each game runs on its own standalone server. A server starts when a player wants to join and shuts down when nobody is playing, which keeps resources free and gives precise control over each game.
